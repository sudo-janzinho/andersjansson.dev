Get started in 2 minutes

No installation. No account. Just download and run.

1. Download Tor Browser (required for Tor mode)
2. Start Tor Browser (keep it running)
3. Download mybrowser.py + mybrowser.bat
4. Double-click mybrowser.bat
5. Done! 🟢 Tor should show green in toolbar
🤖 Important: Audit the code yourself

mybrowser is open source and AI-audited. But we strongly recommend that you run the code through your favorite AI (ChatGPT, Claude, etc.) to verify everything yourself. 318 lines only takes a few minutes to audit. Don't trust us — trust what you can verify yourself.
